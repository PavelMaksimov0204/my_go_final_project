
# Дипломный проект: Планировщик задач

Это веб-сервер на языке Go, который представляет собой API для простого планировщика задач. К серверу прилагается готовый фронтенд для взаимодействия с API.

## Основные возможности

* Добавление, получение, изменение и удаление задач.
* Выполнение задач: обычные удаляются, а повторяющиеся переносятся на следующую дату.
* Поддержка правил повторения: по дням, неделям, месяцам и годам.
* Реализован поиск по задачам.
* Добавлена простая аутентификация по паролю.

---

## Выполненные задания со звёздочкой

* Настройка порта сервера через переменную окружения `TODO_PORT`.
* Настройка пути к файлу базы данных через `TODO_DBFILE`.
* Реализованы сложные правила повторения для задач (по дням недели и месяцам).
* Реализован поиск задач по тексту и дате.
* Реализована аутентификация по паролю.
* Подготовлен `Dockerfile` для запуска приложения.

## Инструкция по запуску

### Локальный запуск

1.  Клонируйте репозиторий.
2.  Установите зависимости командой:
    ```
    go mod tidy
    ```
3.  При необходимости можно настроить переменные окружения:
    * `TODO_PORT`: порт сервера (по умолчанию `7540`).
    * `TODO_DBFILE`: путь к файлу БД (по умолчанию `scheduler.db`).
    * `TODO_PASSWORD`: пароль для доступа. Если не задан, вход свободный.
4.  Запустите сервер:
    ```
    go run main.go
    ```
5.  Откройте в браузере `http://localhost:7540`.

### Запуск тестов

1.  Для тестов с аутентификацией нужно получить токен и прописать его в файле `tests/settings.go` в переменную `Token`.
2.  Для тестов со сложными правилами и поиском в файле `tests/settings.go` установите `FullNextDate = true` и `Search = true`.
3.  Выполните команду:
    ```
    go test ./tests
    ```

### Запуск через Docker

1.  Соберите образ:
    ```
    docker build -t todo-app .
    ```
2.  Запустите контейнер. Пример команды с паролем `12345`:
    ```
    docker run -p 7540:7540 -v "$(pwd)/scheduler.db:/app/scheduler.db" -e TODO_DBFILE="/app/scheduler.db" -e TODO_PASSWORD=12345 --rm --name todo-server todo-app
    ```
